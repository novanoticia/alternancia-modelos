# Política de privacidad de Alternancia de modelos

Última actualización: 13 de noviembre de 2026.

## Alcance

Esta política describe el comportamiento del plugin Alternancia de modelos, mantenido por [novanoticia](https://github.com/novanoticia). El plugin contiene instrucciones y un agente para coordinar las capacidades del entorno donde se instala; no opera un servicio de inferencia propio.

## Datos y comunicaciones del plugin

El plugin no incorpora servidores, telemetría, analítica, publicidad, seguimiento ni mecanismos propios de recogida de datos. No solicita claves API para su funcionamiento y no envía conversaciones, archivos ni resultados al mantenedor.

En Claude, el plugin no añade envíos de datos fuera de Claude ni conexiones a proveedores externos. Cuando la sesión permite delegar, utiliza las capacidades que ofrece Claude y transfiere a los subagentes el contexto necesario para la tarea. Esa delegación puede implicar que Claude procese el contexto de la subtarea.

Las instrucciones pueden pedir una nota de ejecución dentro del resultado o, cuando el usuario lo autorice, en un archivo. El plugin no transmite ese registro a un servicio propio.

## Claude y herramientas autorizadas

El procesamiento, almacenamiento y conservación de las conversaciones por Claude dependen de Anthropic, de las condiciones del servicio y de la configuración de la cuenta. Esta política no sustituye la política de privacidad de Anthropic.

Si el usuario autoriza herramientas, conectores o servicios externos durante una tarea, su uso puede implicar comunicaciones con esos servicios bajo sus propias condiciones. El plugin no incorpora esas integraciones ni concede permisos para utilizarlas.

El repositorio también ofrece compatibilidad con otros clientes. Si se instala fuera de Claude, el tratamiento de datos depende del cliente y de las herramientas autorizadas en ese entorno.

## Soporte

Las consultas enviadas voluntariamente a través de [GitHub Issues](https://github.com/novanoticia/alternancia-modelos/issues) son públicas y se alojan en GitHub conforme a sus condiciones. No publiques contraseñas, claves, conversaciones privadas ni otros datos personales sensibles.

El mantenedor no dispone de una base de datos propia de conversaciones del plugin. Las solicitudes relativas a datos de Claude o GitHub deben dirigirse al servicio correspondiente.

## Cambios

Esta política se actualizará si cambia el comportamiento del plugin. El historial de cambios del documento puede consultarse en el repositorio.
